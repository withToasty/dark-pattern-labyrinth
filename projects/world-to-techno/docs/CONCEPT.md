# Concept

## One sentence

**世界を見て、構成要素を拾い、それをテクノへ翻訳する。**

## 原点

街にはすでに音の意味がある。

- 踏切 → カンカンという反復音
- 自転車 → ベル
- 工事 → 打撃音・機械音
- 水道 → 流水
- 下水 → 流れ・低い環境音
- 寺 → 鐘・和の響き
- 救急車 / パトカー → サイレン
- 車 → 低域・エンジン
- 人 → 声・リズム
- 空 → 余白・アンビエンス・VJ空間

WORLD TO TECHNOでは、
こうした「人間が自然に持っている連想」をルール化し、
映像認識と音楽生成の間に置く。

## 大事にすること

1. **場所への帰属**
   - どこで撮っても同じ曲にはしない。
   - その街・場所にある要素を音へ反映する。

2. **説明可能性**
   - carがbassになった理由が分かる。
   - ブラックボックスの生成だけに頼らない。

3. **映像との同期**
   - 音だけで完結させない。
   - 物体の出現、移動、消失と音の変化を結ぶ。

4. **素材の拡張性**
   - 街だけでなく、食事、祭り、建築、自然へ拡張できる。

5. **人間の編集余地**
   - 完全自動をゴールにしない。
   - 自動生成した後、人が「気持ちいい方」へ直せる設計にする。

## 派生

### City Techno
道路、標識、車、人、工事、建物、空など。

### Food Techno
ハンバーガー、麻婆豆腐などを素材単位に分ける。
食べる動作をミックス操作として扱う。
一口食べた後にgainや音色が変わる。

### Festival / Ritual Techno
輪踊り、掛け声、反復、太鼓、ケチャなど。
集団行動とトランス性を音・映像で扱う。

### Landscape Techno
写真や風景動画を素材にする。
空など情報量の少ない領域はVJ表現のキャンバスにする。
