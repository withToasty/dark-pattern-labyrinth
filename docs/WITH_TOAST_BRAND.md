# WITH TOAST — Brand & Website Design Guide

Status: v0.1 / 2026-09-20  
Purpose: WITH TOASTの企業HP・ポートフォリオ・今後の制作物で使うブランド／デザイン方針の正本。

---

## 1. Company Name

**WITH TOAST**

日本語コピー：

> **トースと、つくる。**

「Toast」は代表者のあだ名「トース」に由来する。

ただし、名前の意味は個人的な由来だけで終わらせない。

トーストはシンプルな土台であり、その上に卵、チーズ、果物、アボカドなど、さまざまなものを載せることで別のものになる。

WITH TOASTも同じように、異なる人・技術・アイデア・分野を組み合わせ、新しいものをつくる場所として捉える。

### Core idea

**Toast is the base.  
Ideas are the toppings.**

- Toast = 土台 / WITH TOAST / トース本人
- Toppings = Ideas / People / Skills / Technologies / Places / Projects
- WITH = 一人で完成させるのではなく、一緒につくること

「BY TOAST」ではなく「WITH TOAST」。

> トースがつくる。  
> ↓  
> トースと、つくる。

---

## 2. Brand Character

WITH TOASTは、特定ジャンルだけに閉じた会社ではない。

ゲーム、映像、音楽、Web、プロダクト、研究など、面白いと思ったものを試し、異なる分野を組み合わせながら形にしていく。

目指す印象：

- Creative studio
- Experimental lab
- Portfolio
- Making log
- Collaboration platform

飲食店・ベーカリーのような見た目にはしない。

「toast」という言葉を、パンの直接的なイラストではなく、**BASE / LAYER / TOPPING / MIX / WITH** というデザイン原理に抽象化する。

---

## 3. Website Theme

### Main concept

**A base where things get layered.**

サイト全体を「Toastという土台に、いろいろなものが乗り、組み合わさってプロジェクトになる」構造で設計する。

### Design principles

1. **Base**
   - WITH TOASTの世界観は静かで一貫している。
   - 背景・タイポグラフィ・余白は落ち着かせる。

2. **Toppings**
   - プロジェクト、分野、人、技術は自由に色や形を持てる。
   - 複数の要素が重なることでプロジェクトになる。

3. **Layers**
   - UI上でも「重なる」「載る」「組み合わさる」を使う。
   - 単なるカード一覧より、タグや要素のレイヤー構造を意識する。

4. **Making**
   - 完成品だけでなく制作途中を見せる。
   - 未完成で動いていること自体をブランドにする。

5. **With**
   - 一人の作品集だけに見せない。
   - 将来的に他のクリエイター、エンジニア、研究者、職人などが参加できる余白を残す。

## 4. Color System

### Primary palette

#### Base Charcoal
**#202020**

- サイトの主背景
- WITH TOASTの基本色
- 黒より少し柔らかく、実験的・クリエイティブな印象
- ダークモードを基本とする

#### Warm Cream
**#F2EBDD**

- メイン文字色
- 明るいセクションの背景
- 真っ白より温度があり、Toastのニュアンスを間接的に持たせる

#### Toast Orange / Brown
**#C56A3D**

- ブランドアクセント
- 焼き色、熱、制作中のニュアンス
- 使用量は抑える
- ホバー、リンク、進捗、MAKINGラベル、小さな強調などに使用

#### Soft Gray
**#8E8E8E**

- 補足文
- 日付
- ステータス
- メタ情報

### Secret accent / Anniversary Indigo

**#202688**

2026-08-08の結婚記念日を由来とする隠し色。

RGB: 32 / 38 / 136  
印象: 深いインディゴ〜青紫。

これはブランドの主要色にはしない。

**ごく稀にだけ使う。**

使用候補：

- 小さなホバー
- フッターの点
- 404ページ
- ローディング時の一瞬
- プロジェクト番号
- ロゴや文字のごく一部
- Easter egg

「知らなくても成立する。知っていると意味がある」程度に留める。

## 5. Color Philosophy

**Base stays calm. Projects bring color.**

WITH TOAST本体は、

- Charcoal
- Cream
- Toast Orange

を中心に静かに保つ。

一方、各プロジェクトは独自の色を持ってよい。

例：

- GAME
- MUSIC
- FILM
- TECH
- RESEARCH

これらに固定のカテゴリカラーを必ず割り当てる必要はない。

重要なのは、

> **会社自体はキャンバス。プロジェクトが色を持つ。**

という考え方。

---

## 6. Typography

基本は無機質で読みやすいサンセリフ。

候補の方向性：

- Helvetica系
- Neue Haas系
- Inter系
- Geist系

可愛すぎる丸文字、パン屋・カフェを強く連想させる書体は避ける。

基本はクリーンで現代的。

必要なら「Toast」や注釈の一部だけ、少し人間味のある表現を入れてもよい。

## 7. UI / Interaction

### Keywords

- Layer
- Stack
- Mix
- Combine
- Hover
- Making
- Progress

### Hero

トップは静かに始める。

例：

WITH TOAST

トースと、つくる。

周囲に小さく、

GAME  
FILM  
MUSIC  
TECH  
RESEARCH

などの要素が浮いている。

スクロールや操作に応じて、それらが重なり、一つのプロジェクトへ変化する表現を検討する。

例：

CITY  
+ VIDEO  
+ AI  
+ TECHNO  

→ CITY TECHNO PROJECT

### Project metadata

一般的な「Tech Stack」だけではなく、WITH TOASTでは可能なら

**INGREDIENTS**

という表現を使う。

例：

INGREDIENTS

- Video
- Computer Vision
- Techno
- Tokyo

ただし、分かりにくさが勝つ場合はUI上に説明を添える。

### Project status

制作状態を可視化する。

- IDEA
- EXPERIMENT
- MAKING
- DONE

必要に応じて進捗を表示する。

例：

MAKING  
──────────── 62%

「完成したものだけを並べるポートフォリオ」にはしない。

## 10. Light / Dark Sections

基本はCharcoal背景。

ただし全ページを暗く固定する必要はない。

例：

- HOME / PROJECTS → Charcoal
- WHY TOAST? → Warm Cream

社名の由来ページに入った瞬間に背景が明るくなるなど、ページ遷移にも意味を持たせてよい。

イメージ：

**Dark outside, warm inside.**

ただし、この英語コピー自体を正式なブランドコピーとして採用したわけではない。

---

## 11. Motion

動きはブランド理解のために使う。

良い動き：

- 要素が重なる
- タグが組み合わさる
- 色が現れる
- BY → WITHへ変わる
- 制作進捗が動く

避ける：

- 意味のない派手な3D
- 常に動き続ける背景
- 読みにくくなる演出
- パンが飛び回るような直接的な食品表現

---

## 12. What NOT to Do

WITH TOASTは以下に見せない。

- パン屋
- ベーカリー
- カフェ
- 食品ブランド
- 可愛さ中心のキャラクターブランド

Toastはモチーフではあるが、パンそのものを主役にしない。

**「パンの会社」ではなく、「異なるものを載せ、混ぜ、つくる会社」。**

## 14. Implementation Principle

デザイン判断に迷った場合は、次の順番で考える。

1. WITH TOASTの思想が伝わるか
2. 「重なる・組み合わさる」が表現できているか
3. 制作途中も魅力として見せられているか
4. 飲食店に見えていないか
5. 見た目の派手さより読みやすさを保てているか
