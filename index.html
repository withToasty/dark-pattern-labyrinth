よくあるダークパターン

今回登場したのは、実際のWebサービスでも見られることがある代表的な手法です。

Obstruction / 妨害
解約までの階層・手順を不必要に長くする。
Misdirection / 誘導
継続・アップグレードだけを目立たせる。
Roach Motel
登録は簡単、退会だけ異常に難しい。
Interface Interference
×、色、大きさ、配置などUIの常識を利用して誤操作させる。
Forced Action
退会に不要なアンケート・再ログイン・追加操作を要求する。
Loop / Dead End
FAQ・チャット・ログインを循環させて到達を困難にする。
Fake Progress
「あと2STEP」「92%完了」などで終わりが近いように見せる。
いちばん重要
UIの見た目ではなく、自分が何をしたいのかを基準に判断する。
